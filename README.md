# ⚔️ Rust Text RPG

Rust 언어의 핵심 문법과 철학을 직접 실습하며 배우기 위해 제작하는 **콘솔 기반 턴제 던전 텍스트 RPG**입니다.

---

## 📖 프로젝트 개요

플레이어는 모험가가 되어 마을에서 정비하고, 던전을 탐험하며 몬스터와의 1:1 턴제 전투를 통해 캐릭터를 성장시킵니다. 던전 최심부(5층)에 서식하는 **최종 보스(고대 화염룡)**를 처치하면 게임을 클리어하게 됩니다.

- **조작 방식**: 콘솔 메뉴 번호 선택 방식 (`[1]`, `[2]`, `[3]`)
- **장르**: 턴제 던전 탐험 & 캐릭터 육성 RPG
- **목표**: 5층 최종 보스 격파 및 게임 클리어
- **학습 목표**: 소유권, 빌림, 패턴 매칭, 트레이트 등 Rust 핵심 개념 체득

## 🗺️ 단계별 개발 및 학습 로드맵

```
[1단계] 입출력 & 변수 (기본 루프)
   │
[2단계] 구조체(Struct) & 메서드 (플레이어 스탯)
   │
[3단계] 열거형(Enum) & 패턴 매칭 (게임 상태 전환)
   │
[4단계] 모듈화 & 대여(Borrowing) (턴제 전투 & 몬스터)
   │
[5단계] 컬렉션(Vec) & 소유권 이동(Move) (인벤토리 & 아이템)
   │
[6단계] 트레이트(Trait) (공통 엔티티 추상화)
   │
[7단계] 던전 층(Floor) & 최종 보스전 (게임 완성)
   │
[8단계] (심화) 세이브/로드 & 에러 핸들링 (Serde & File I/O)
```

## 🛠️ 실행 방법 (예정)

Rust 컴파일러와 Cargo가 설치되어 있어야 합니다.

```bash
# 빌드 및 실행
cargo run

# 릴리즈 빌드 실행
cargo run --release
```
