# Rust Text RPG - 게임 기획 및 설계서

## 1. 프로젝트 개요
본 프로젝트는 **Rust**로 개발하는 콘솔 기반 **턴제 던전 텍스트 RPG**입니다.  
플레이어는 모험가가 되어 마을과 던전을 오가며 몬스터를 사냥하고, 캐릭터를 성장시켜 최종 층에 위치한 **최종 보스를 처치**하는 것을 목표로 합니다.

---

## 2. 게임 핵심 방향성
- **조작 방식**: 콘솔 메뉴 번호 선택 방식 (`[1]`, `[2]`, `[3]` 등 번호 입력)
- **장르**: 턴제 던전 탐험 & 캐릭터 육성 RPG
- **최종 목표**: 던전 최심부의 최종 보스 격파 (클리어 조건)
- **설계 철학**: 직관적이고 단순한 코어 루프를 우선 구현하고, 단계적으로 확장 가능한 모듈형 구조 지향

---

## 3. 핵심 게임 루프 (Core Game Loop)

```
[마을 (Town)]
  ├─ [1] 던전 입장 (Dungeon) ──> [전투/이벤트 발생] ──> [승리: EXP/골드 획득] ──> [성장/귀환]
  ├─ [2] 상점 방문 (Shop)    ──> 장비 구매, 회복 물약 구매
  ├─ [3] 여관/휴식 (Inn)     ──> HP/MP 완전 회복
  ├─ [4] 캐릭터 상태 (Status) ──> 스탯 확인, 장비 착용
  └─ [5] 게임 저장 / 종료 (Save/Quit)
```

1. **마을(Town)**: 거점 역할을 하며 장비 정비, 물약 구매, 휴식 가능
2. **던전 탐험(Dungeon)**:
   - 층(Floor) 단위로 진행 (예: 1층 ~ 5층)
   - 층마다 몬스터 조우 또는 랜덤 이벤트 발생
   - 특정 층마다 중간 보스, 마지막 층에 최종 보스 배치
3. **전투(Combat)**:
   - 플레이어와 몬스터 간의 1:1 턴제 전투
   - 행동 선택: 일반 공격, 스킬 사용, 아이템 사용, 도망
4. **성장(Progression)**:
   - 전투 승리 시 경험치(EXP) 및 골드(Gold) 획득
   - 레벨업 시 최대 HP/MP 및 기본 공격력/방어력 상승
5. **목표 달성(Game Clear)**:
   - 최종 보스를 처치하면 엔딩 출력 후 게임 클리어

## 4. 세부 시스템 정의

### 4.1. 캐릭터 및 성장 시스템
- **기본 스탯**:
  - `HP` (현재 체력 / 최대 체력)
  - `MP` (현재 마나 / 최대 마나 - 스킬 사용)
  - `ATK` (공격력)
  - `DEF` (방어력)
  - `Level` (레벨)
  - `EXP` (현재 경험치 / 다음 레벨 경험치)
  - `Gold` (소지 골드)
- **장비/인벤토리**:
  - 무기 (ATK 증가)
  - 방어구 (DEF 및 최대 HP 증가)
  - 소모품 (HP 회복 포션, MP 회복 포션 등)

### 4.2. 던전 및 조우 시스템
- 던전 진입 시 단계별 층(Floor) 진행
- 각 층 진행 선택지:
  - `[1] 전진 (다음 방/몬스터 탐색)`
  - `[2] 아이템 사용 (회복)`
  - `[3] 마을로 귀환 (포기/정비)`
- **던전 구성 예시**:
  - 1층 ~ 2층: 초급 몬스터 (슬라임, 고블린 등)
  - 3층 ~ 4층: 중급 몬스터 (오크, 스켈레톤 등)
  - 5층: 최종 보스 (드래곤 / 마왕)

### 4.3. 턴제 전투 시스템
전투 화면에서 매 턴 행동 메뉴를 출력하고 번호로 선택:
- `[1] 일반 공격`: 기본 공격력 기반 데미지 공식 적용
- `[2] 스킬 공격`: MP를 소모하여 강력한 피해 또는 특수 효과
- `[3] 포션 사용`: 인벤토리의 포션을 소모하여 HP/MP 회복
- `[4] 도망치기`: 일정 확률로 마을 또는 안전지대로 탈출

**데미지 공식 (기본 안)**:
$$\text{Damage} = \max(1, \text{Attacker ATK} - \text{Defender DEF})$$

## 5. Rust 아키텍처 및 모듈 구성 (예정)

```
src/
 ├─ main.rs          # 프로그램 진입점 및 메인 루프
 ├─ game.rs          # 전체 게임 상태(GameState) 및 메인 씬 흐름 관리
 ├─ player.rs        # Player 구조체, 스탯, 레벨업 로직
 ├─ monster.rs       # Monster 구조체 및 몬스터 팩토리/데이터
 ├─ combat.rs        # 턴제 전투 루프 및 데미지 계산
 ├─ dungeon.rs       # 던전 층 관리 및 진행 로직
 ├─ item.rs          # Item, Inventory, 상점(Shop) 관련 구조체
 └─ io_helper.rs     # 터미널 입력(번호 선택 파싱), 출력 편의 함수
```

## 6. 향후 개발 단계 (Roadmap)
1. **1단계**: Rust 프로젝트 셋업 (`cargo init`) 및 입출력 헬퍼(`io_helper`) 구현
2. **2단계**: `Player` 스탯 구조체 및 기본 콘솔 메뉴 루프 구축
3. **3단계**: `Monster` 구조체 및 턴제 전투 시스템 구현
4. **4단계**: 던전 층(Floor) 진행 및 최종 보스 조우 로직 구현
5. **5단계**: 마을 거점(상점, 여관, 인벤토리 관리) 구현
6. **6단계**: 밸런스 조정 및 게임 완성
